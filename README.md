# Etherbill Server

Etherbill is blockchained powered escrowed-based deals-market place with in-built invoicing system for any kind of contractual business.

## Feature of Etherbill API

- Secure user Authentication
- Multi-core system functionality. (Load balancing & Fault Tolerant)
- Email notification

## Usage

- Installation of packages `npm install`
- Run `node App.js`
